CONFIGURACIÓN

1. Sube todo este contenido a un repositorio GitHub.
2. En admin/config.yml sustituye TU_USUARIO/TU_REPOSITORIO.
3. Activa GitHub Pages usando GitHub Actions.
4. Decap CMS estará en /admin/.
5. Los cambios del CMS se guardan como commits en GitHub y GitHub Pages los publica para todos.
6. Las imágenes seleccionadas en Decap se guardan en /imagenes.

IMPORTANTE: Decap necesita autenticación OAuth para escribir en GitHub. No pongas un token personal de GitHub en el JavaScript público. Para mantener xavibc1976@gmail.com como administrador protegido, configúralo como cuenta autorizada en el proveedor OAuth.

Los formularios y el envío de correos requieren un servicio externo porque GitHub Pages es estático.
